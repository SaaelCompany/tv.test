# LotAi

Витрина оформлена как подписка на облачные модели. Оплата по-прежнему создаёт клиента в панели 3x-ui. Реквизиты, ИНН и тексты политики с офертой правятся в `/admin`.

Установка на сервер с Ubuntu, из каталога с кодом:

```bash
sudo XUI_API_TOKEN=... bash install.sh
sudo DOMAIN=ai.example.com XUI_API_TOKEN=... bash install.sh
```

Без `DOMAIN` сайт открывается по IP на порту 8000. Повторный запуск обновляет код и не перезаписывает `.env`, пока не задан `RECONFIGURE=1`.

Новый оплаченный заказ заводит отдельную подписку. Продление в кабинете добавляет дни и трафик к выбранной подписке и не меняет её ссылку. Имя клиента в панели — почта пользователя (`user+2@mail` для второй подписки), комментарий — название тарифа: из этих полей панель собирает имя в подписке (`{{EMAIL}}`, `{{COMMENT}}`). Срок, квота и израсходованный трафик подтягиваются из панели при открытии кабинета и по таймеру `XUI_SYNC_INTERVAL`.
